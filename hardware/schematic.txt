Mole Repeller Next Generation — Circuit Diagrams
=================================================
Target MCU: ESP32 DevKit C


╔══════════════════════════════════════════════════════════════════════════════╗
║  CIRCUIT 1 — 12V VIBRATION MOTOR via RELAY                                  ║
║  GPIO25  →  Relay module  →  12V vibration motor                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

  +12V supply
      │
    [COM] ── Relay contacts (SRD-05VDC or equivalent 10A relay module)
    [NO ] ──────────────────────────────┐
                                        │
                                     ┌──┴──┐
                              ┌──────┤  M  ├──────┐
                              │      │ 12V │      │
                              │      └─────┘      │
                              │   Vibration Motor  │
                              │                   │
                           1N4001              12V GND (shared GND)
                          (flyback,
                          cathode to
                          motor +)

  Relay module control side:
      VCC  ──── 5V  (ESP32 DevKit 5V pin, or dedicated 5V reg)
      GND  ──── GND (shared with ESP32 and 12V supply)
      IN   ──── see below

  ┌─ Option A: relay module with 3.3V-compatible input (recommended) ──────────┐
  │  Many modules (e.g. KEYES with HEF4001 optocoupler) work at 3.3V logic:   │
  │  GPIO25 ────────────────────────────── Relay IN                            │
  └────────────────────────────────────────────────────────────────────────────┘

  ┌─ Option B: standard relay module needs 5V signal ─────────────────────────┐
  │  Add a 2N2222 level-shift transistor:                                      │
  │                                                                            │
  │    5V ──[1kΩ]──── Relay IN                                                 │
  │                      │                                                     │
  │                   COLLECTOR                                                 │
  │                 ──┤ Q1: NPN (2N2222)                                       │
  │                   └──┐                                                     │
  │          [1kΩ] ──────┤ BASE ◄── GPIO25 (ESP32, 3.3V)                      │
  │                   EMITTER                                                  │
  │                      │                                                     │
  │                     GND                                                    │
  └────────────────────────────────────────────────────────────────────────────┘

  Component list:
    K1   Relay module     5V coil, 10A contacts, optocoupler input
                          e.g. SRD-05VDC-SL-C based module
    Q1   NPN transistor   2N2222A  (Option B only)
    R1   Resistor         1kΩ  ¼W  (Q1 base, Option B only)
    R2   Resistor         1kΩ  ¼W  (5V pull-up, Option B only)
    D1   Diode            1N4001   (flyback across motor terminals, always required)
    C1   Capacitor        100nF ceramic  (across motor terminals, suppresses arcing)
    M1   Vibration motor  12V DC with eccentric weight
                          e.g. 775-series DC motor + bolt-on eccentric weight,
                          or dedicated 12V vibration motor

  Notes:
    • 12V motor delivers far more mechanical energy than the 3V coin motors
      used in commercial repellers — much better ground coupling via stake.
    • Relay switching is on/off only — no PWM. Pattern timing controls the
      vibration character instead of motor speed.
    • Relay coil draws ~70–90mA from the 5V rail — use the DevKit 5V pin
      (USB-powered) or a separate 5V regulator. Do not use the ESP32 3.3V pin.
    • 12V and logic GND must be tied together at one point.

                            │
                            ├ ◄── COLLECTOR
                         ┌──┘
                       ──┤  Q2: NPN  (2N2222 / BC547)
                         └──┐
                    ┌────────┤ ◄── BASE
                    │
                  [1kΩ]
                    │
                  GPIO26 (ESP32, 3.3V output)

                         ──┐
                            └──┤ ◄── EMITTER
                               │
                            ┌──┴──┐
                            │  8Ω │  Speaker  (0.5W min)
                            │ SPK │
                            └──┬──┘
                               │
                              GND

  Component list:
    Q2   NPN transistor   2N2222A  (or BC547)
    R2   Resistor         47Ω  ¼W
    R3   Resistor         1kΩ  ¼W  (base resistor — limits GPIO current)
    SPK  Speaker          8Ω  0.5W

  Notes:
    • ESP32 GPIO outputs 3.3V; 2N2222 base threshold is ~0.6V so it switches
      reliably from 3.3V with a 1kΩ base resistor.
    • Volume limited — suitable for bench testing only.
    • For outdoor use where speaker must project through soil, use Circuit 2B.


╔══════════════════════════════════════════════════════════════════════════════╗
║  CIRCUIT 2B — SPEAKER DRIVER (LM386 MODULE, recommended for outdoor)        ║
║  GPIO26  →  LM386 amplifier module (4 pins)  →  8Ω speaker                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

  Use a pre-built LM386 amplifier MODULE — not the bare IC.
  The module has the LM386 chip + all capacitors already soldered on board.
  It exposes only 4 pins. Search: "LM386 Mini Audio Amplifier Module" (~€1–2)

  Wiring — just 4 connections:

                    ┌─────────────────────┐
                    │   LM386 MODULE      │
                    │   (pre-built PCB)   │
         5V ───────►│ VCC                 │
        GND ───────►│ GND                 │
     GPIO26 ───────►│ IN                  │
                    │ OUT ────────────────┼──── Speaker (+)
                    └─────────────────────┘
                                               Speaker (-) ──── GND

  That's it. No extra capacitors or resistors needed — they are on the module.

  Component list:
    MOD1  LM386 amplifier module   Pre-built PCB, 4 pins (VCC/GND/IN/OUT)
                                   3V–12V supply, ~1W output into 8Ω
                                   All passive components included on board
    SPK   Speaker                  8Ω  1W–2W, 57mm or larger for best
                                   low-frequency response and soil coupling

  Notes:
    • GPIO26 (3.3V) connects directly to module IN — no level shift needed.
    • Larger speaker cone = more acoustic energy transmitted into soil.
    • Mount speaker face-down on a steel plate pressed into soil to maximise
      low-frequency ground coupling.

║  FULL SYSTEM OVERVIEW                                                        ║
╚══════════════════════════════════════════════════════════════════════════════╝

  12V supply ──────────────────────────── Relay COM → Motor
                                          Relay coil (via 5V module)

  5V supply (USB or regulator)
      │
      ├──── ESP32 DevKit C (VIN or 5V pin)
      │         │
      │       [MCU]  ESP32 DevKit C
      │         │
      │    GPIO25 ──────────► Relay module IN → 12V motor
      │    GPIO26 (tone()) ─► LM386 amp       → Speaker
      │    GPIO34 (ADC, float) entropy source for PRNG seed only
      │    GPIO2  (LED)    ─► status indicator (onboard)
      │
     GND ──────────────────── shared (ESP32 + relay module + 12V supply -)

  Power options:
    A) USB power bank (5V) → DevKit USB → powers ESP32 + relay coil
       Separate 8× AA (12V) or 3S LiPo (11.1V) → motor via relay
    B) 12V SLA battery → relay motor
       12V → HT7550 / LM7805 regulator → 5V → DevKit VIN
       (single supply for whole system)
    C) 12V Li-ion pack (3S, 11.1V nominal)
       → XL4016 buck converter → 5V → DevKit
       → relay COM directly

  Ground spike installation:
    ┌────────────────────────────────────────────────────────┐
    │  Weatherproof box (IP65 ABS)                           │
    │  [ESP32]  [LM386]  [Relay module]  [5V reg]  [Battery] │
    └────────────┬────────────────────────────────────────── ┘
                 │ cable glands (PG7 / M12)
                 │
          Motor leads ──► motor bolted to top of stake
          Speaker leads ─► speaker face-down on base plate
                 │
    ┌────────────▼──────────────┐
    │  ▓▓▓▓▓▓▓  Ground Stake    │  30–50 cm steel rod or rebar
    │  ▓▓▓▓▓▓▓  driven into     │  driven into soil
    │  ▓▓▓▓▓▓▓  soil            │
    └───────────────────────────┘
